# 🌸 Women-Health

A comprehensive **Women’s Health Desktop Application** designed to provide accessible information about common women's health conditions, including symptoms, nutrition, lifestyle recommendations, and exercises.

The application is built with **Python, Tkinter, and CustomTkinter** and provides an interactive, modern dark-themed desktop interface.

---

## ✨ Features

- 🌸 **Women's Health Disease Database**

  - PCOS (Polycystic Ovary Syndrome)
  - Endometriosis
  - Breast Cancer
  - Osteoporosis
  - Thyroid Disorders
  - Menopause
  - Uterine Fibroids
  - And other women's health conditions

- 🩺 **Health Information**

  - Condition descriptions
  - Common symptoms
  - Health categories
  - General lifestyle information

- 🥗 **Nutrition Guidance**

  - Foods that may be beneficial
  - Foods that may be worth limiting
  - Nutrition-related recommendations for different conditions

- 🏃‍♀️ **Exercise Recommendations**

  - Recommended exercises
  - Suggested duration/frequency
  - Potential benefits of different activities

- 🎨 **Modern User Interface**

  - Dark-themed interface
  - Custom colors and visual components
  - Interactive desktop UI
  - Emoji-based visual indicators for better navigation

- 🖥️ **Desktop Application**

  - Runs locally on a computer
  - Built using Python GUI technologies
  - No browser required

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/prachikaneriya23/Women-Health.git
```

### 2. Navigate to the Project

```bash
cd Women-Health
```

### 3. Install Dependencies

Make sure Python is installed on your system, then install the required packages:

```bash
pip install customtkinter pillow requests
```

Tkinter is normally included with standard Python installations. On some Linux distributions, it may need to be installed separately.

---

## ▶️ Run the Application

Run the following command:

```bash
python ssd.py
```

The Women-Health desktop application should launch in a graphical window.

## 🩷 Health Conditions

The application contains structured information for multiple women's health conditions.

For example, the built-in database includes information related to:

### PCOS

Information includes:

- Symptoms such as irregular periods, acne, weight changes, and mood changes
- Nutrition recommendations
- Exercise suggestions such as walking, yoga, strength training, swimming, and cycling

### Endometriosis

Information includes:

- Pelvic pain
- Heavy periods
- Fatigue
- Bloating
- Lifestyle and nutrition information
- Low-impact exercise recommendations

### Breast Cancer

Information includes:

- Common warning signs
- Nutrition information
- Exercise and lifestyle recommendations

### Osteoporosis

Information includes:

- Bone-health information
- Calcium and vitamin-D-related nutrition
- Weight-bearing and resistance exercises

### Thyroid Disorders

Information includes:

- Common symptoms
- Nutrition information
- Exercise and lifestyle recommendations

### Menopause

Information includes:

- Hot flashes
- Night sweats
- Sleep issues
- Mood changes
- Nutrition and exercise recommendations
